Document–Memory Agreement

Per-query z-score normalisation maps both views to zero mean and unit variance before summing: szfinal(d) = ẑD(d) + ẑM(d) where ẑ = (s − μq) / σq is computed over each view's retrieved candidates for query q. Absent view scores are zero. The sum carries no weight — Z-Agreement is parameter-free and still achieves the best MuSiQue R@10 (90.36).

Why z-normalise?

Both trees produce cumulative path scores — products of per-hop cosine similarities from the same encoder — so the two views already live in comparable ranges (the paper's diagnostics report a median σD/σM ≈ 1.09). They are not on wildly different scales. What does differ, query to query, is each view's spread: one view can be more tightly bunched than the other, which lets the wider-spread view dominate a plain sum. Z-scoring each view independently (zero mean, unit variance across that view's retrieved docs) removes that spread mismatch, so a document is rewarded for being strong relative to its own view's distribution rather than for the view it happens to come from.

Memory scores are first projected to document level by taking the max score per source document: sM(d) = maxm: π(m)=d sM(m). The z-normalisation is then applied to each view's projected scores, and the two standardised scores are simply summed. There is no weight or bonus term — a document ranks highly precisely when both views agree it is above average.

Plain-additive ablation (γ)

Z-Agreement is the headline method and is parameter-free. The appendix also reports a simpler ablation — a plain additive sum of the raw path scores, sfinal(d) = sD(d) + sM(d) — with an optional multiplicative agreement factor on documents found by both views: (sD + sM) · (1 + γ). Here γ is a property of the plain variant only, never of Z-Agreement. Switch the demo to Plain additive to expose the γ slider: positive γ boosts intersected docs, negative γ penalises them. Across the sweep, parameter-free Z-Agreement still gives the strongest MuSiQue R@10, which is why it — not the γ-tuned plain sum — is the default.
