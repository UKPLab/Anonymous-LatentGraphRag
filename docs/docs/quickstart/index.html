Quickstart

This page runs the whole pipeline once: constructed knowledge with provenance, retrieval with two recursive trees, a seeded ReAct agent, and grading. Each step has its own guide.

You need:

  • documents: the corpus as {document id: text}.
  • Constructed knowledge: a HippoRAG-format OpenIE file (triples) and/or a PropRAG output file (propositions). Both are keyed by chunk id; chunk_to_doc maps a chunk id to the document id it belongs to.
  • An RDR checkpoint, and an OpenAI-compatible chat endpoint for the agent.

1. Constructed knowledge

Each triple becomes the literal sentence "head relation tail."; each memory keeps the list of documents it was extracted from. See Knowledge construction.

2. Retrieval

index.save("lgr_index") writes the encoded index to a directory, and lgr.load_index("lgr_index") loads it later without encoding anything again; the whole workflow is on Index a corpus, save, reuse.

PAPER is the configuration behind every LatentGraphRAG row of the paper. view="D" gives the documents-only configuration; other views and operators are on the Retrieval page.

3. A seeded ReAct agent

The top ten documents of the ranking become the agent's initial evidence. The agent's own search tool is a plain embedding search over a fixed index; embeddings are the precomputed document embeddings of that index.

What agent.run does with a LatentGraphRAG seed, on a released MuSiQue question whose seed holds three of the four passages it needs: one search for the missing one, then the answer.
