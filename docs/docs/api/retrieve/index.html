retrieve()

The main retrieval entry point. Dispatches on three orthogonal axes (corpus × search × fusion) and returns List[RetrievalResult].

Signature

Return type

python
@dataclass
class RetrievalResult:
    query: str                              # the input query
    documents: List[str]                    # top-k document ids, sorted by score desc
    scores: List[float]                     # aligned with .documents
    memories: List[str]                     # memory hash_ids surfaced
    paths: List[List[Any]]                  # full per-hop paths (debugging)

Validation rules

All validation runs at call-time. Invalid combinations raise ValueError with a message that names the rule:

Rule violatedError message
fusion ∈ {rrf, agreement} requires corpus='dual_tree'Fusion is only meaningful when corpus='dual_tree' — single-view retrieval has nothing to fuse.
search='cross_view_beam' requires corpus='dual_tree'search='cross_view_beam' requires corpus='dual_tree'.
corpus ∈ {memory_only, joint_index, dual_tree} requires build_graph()Memory-only / joint / dual modes require a relational memory index. Call build_graph() first (with openie_llm set).
corpus value not in {document_only, memory_only, joint_index, dual_tree}Invalid corpus='...'. Expected one of [...].
search value not in {full_expansion, beamdr, cross_view_beam, mmr, single_hop}Invalid search='...'. Expected one of [...].
fusion value not in {rrf, agreement, none, None}Invalid fusion='...'. Expected rrf/agreement/none/None.

Canonical configurations

python
# Document-Only Full Tree (b=3, H=4)  — strong document baseline
rag.retrieve(q, corpus="document_only", search="full_expansion",
             branching=3, max_hops=4)

# Memory-Only Full Expansion           — best on FanOutQA
rag.retrieve(q, corpus="memory_only", search="full_expansion",
             branching=3, max_hops=4)

# BeamDR (B=10) over documents
rag.retrieve(q, corpus="document_only", search="beamdr",
             beam_width=10, max_hops=4)

# Joint-Index Tree Search (b=5)
rag.retrieve(q, corpus="joint_index", search="full_expansion",
             branching=5, max_hops=4)

# Dual RRF, Full Expansion             — best calibration-free fusion
rag.retrieve(q, corpus="dual_tree", search="full_expansion",
             fusion="rrf", branching_doc=3, branching_memory=5)

# Full Dual-Tree + Agreement           — best MuSiQue R@10 (90.36)
rag.retrieve(q, corpus="dual_tree", search="full_expansion",
             fusion="agreement", branching_doc=3, branching_memory=5,
             gamma=0.0)

# Cross-View Beam (B=10)               — best MuSiQue R@5 (83.21)
rag.retrieve(q, corpus="dual_tree", search="cross_view_beam",
             beam_width=10, max_hops=4)
