Evaluation

latentgraphrag.evaluation holds the reader, the grader and the metrics behind the paper's tables: retrieve-then-read answers, graded answers for single-answer benchmarks, loose list recall for list-valued answers, and recall@k for rankings.

Retrieve-then-read

Reader answers from a seed without searching. It is the agent's controller model with the read-only prompt: its first turn is identical to the agent's (the seed as numbered documents, then the question), and a turn without an answer line receives one follow-up request for it. Context fitting is off.

Reader(llm, max_tokens=8192, followup_max_tokens=512, frequency_penalty=0.4, context_length=65536, retry_sleep=3.0). read returns a one-step Trajectory, the same type the agent returns, so readers and agents are graded and exported alike.

Grading

BrowseCompGrader applies the official BrowseComp grader template. The paper grades with the controller model itself at temperature 0.

The grader sees the final answer line only: Exact Answer: … taken from the last answer line of the output, or the last 2,000 characters of the output when it has none. This keeps long reasoning out of the grader's input.

Answer metrics

List-valued answers (FanOutQA) are scored by loose list recall: the share of gold list items found in the response. The gold answer is split on ;. An item key: value counts when every token of its normalized key and value occurs in the normalized response; an item without : counts when every token of its value does.

FunctionDescription
loose_list_recall(response, gold)loose list recall of a response; gold as a string or a list (joined with "; ")
loose_final(output, gold)loose list recall on the final answer text: everything after the last Exact Answer:, so answers continued over several lines count; the whole output without an answer line
final_answer_line(output)only the line after the last Exact Answer:
final_answer_text(output)the final answer text used by loose_final and Trajectory.final_answer
normalize_text(text)lower-case, runs of non-alphanumeric characters to one space

Retrieval metrics

Gold labels are either a set of document ids (recall is the fraction retrieved) or groups of interchangeable documents, {group: set of ids} (recall is the fraction of groups with at least one retrieved member, as for FanOutQA source groups). retrieval_metrics averages recall@k over the questions that have gold labels and reports their number as queries_with_gold.
