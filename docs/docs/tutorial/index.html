Before you start

You'll need Python 3.10+, a few minutes, and either an OpenAI-compatible API key OR a CUDA-capable machine for self-hosted vLLM. The five-document corpus we use fits on a laptop; nothing about the tutorial requires the full encoder weights — the steps explain how to plug in lighter alternatives.
