# Quickstart

This page runs the whole pipeline once: constructed knowledge with provenance, retrieval with two recursive
trees, a seeded ReAct agent, and grading. Each step has its own guide.

You need:

- `documents`: the corpus as `{document id: text}`.
- Constructed knowledge: a HippoRAG-format OpenIE file (triples) and/or a PropRAG output file (propositions).
  Both are keyed by chunk id; `chunk_to_doc` maps a chunk id to the document id it belongs to.
- An RDR checkpoint, and an OpenAI-compatible chat endpoint for the agent.

## 1. Constructed knowledge

```python
from latentgraphrag import MemoryInventory, chunk_id, propositions, triples

# The OpenIE caches key passages by "chunk-" + md5(title + "\n" + text).
chunk_to_doc = {chunk_id(title, text): doc_id for doc_id, (title, text) in titled_passages.items()}

tri = triples.from_openie(triples.load_openie("openie.jsonl.gz"), source_of=chunk_to_doc)
pro = propositions.from_records(propositions.load_records("proprag_openie.json"), source_of=chunk_to_doc)
inventory = MemoryInventory.union(tri, pro)   # one memory index, provenance merged

inventory.stats()   # {"memories": ..., "triple": ..., "proposition": ..., "sources": ...}
```

Each triple becomes the literal sentence `"head relation tail."`; each memory keeps the list of documents it
was extracted from. See [Knowledge construction](/docs/construction).

## 2. Retrieval

```python
from latentgraphrag import PAPER, LatentGraphRAG

lgr = LatentGraphRAG("path/to/rdr-checkpoint", config=PAPER)
index = lgr.build(documents, inventory, cache_dir="cache/my-corpus")

question = "Who founded the company that ..."
result = lgr.search([question], index, k=10)[0]

result.ranking        # [(document id, score), ...], best first
result.ids            # the document ids alone
result.document_view  # document tree, {document id: score}
result.memory_view    # memory tree projected to documents, {document id: score}
```

`index.save("lgr_index")` writes the encoded index to a directory, and `lgr.load_index("lgr_index")` loads it
later without encoding anything again; the whole workflow is on [Index a corpus, save, reuse](/docs/indexing).

`PAPER` is the configuration behind every LatentGraphRAG row of the paper. `view="D"` gives the documents-only
configuration; other views and operators are on the [Retrieval](/docs/retrieval) page.

## 3. A seeded ReAct agent

The top ten documents of the ranking become the agent's initial evidence. The agent's own search tool is a
plain embedding search over a fixed index; `embeddings` are the precomputed document embeddings of that index.

```python
from latentgraphrag import DenseSearchTool, OpenAIChatModel, ReActAgent, Seed

llm = OpenAIChatModel(model="Qwen/Qwen3.5-122B-A10B", base_url="http://localhost:8000/v1")

ids = list(documents)
search_tool = DenseSearchTool(embeddings, [documents[d] for d in ids], ids)

agent = ReActAgent(llm, search_tool)                          # at most ten searches
seed = Seed.from_ranking(result.ids, documents)               # top 10, each cut to 2,200 characters
trajectory = agent.run(question, seed)

trajectory.final_answer   # text after the last "Exact Answer:"
trajectory.tool_calls     # searches issued (the seed is not one)
```

What `agent.run` does with a LatentGraphRAG seed, on a released MuSiQue question whose seed holds three of the
four passages it needs: one search for the missing one, then the answer.

## 4. Grading

```python
from latentgraphrag import BrowseCompGrader, loose_final

verdict = BrowseCompGrader(llm).grade(question, trajectory.output, gold_answer)
verdict.correct    # True, False, or None when the grader gave no verdict (counted as incorrect)

loose_final(trajectory.output, gold_list)   # list-valued answers, as for FanOutQA
```

Retrieve-then-read without an agent uses `Reader(llm).read(question, seed)` instead of the agent. See
[Evaluation](/docs/evaluation).
