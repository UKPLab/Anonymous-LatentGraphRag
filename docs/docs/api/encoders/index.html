Encoders

A tiny ABC plus four bundled backends. Encoders are pluggable — anything implementing the BaseEncoder interface composes with every corpus mode, search strategy, and fusion method.

BaseEncoder

python
from abc import ABC, abstractmethod
from typing import List, Optional
import numpy as np

class BaseEncoder(ABC):
    dim: int
    normalize: bool = True

    @abstractmethod
    def encode(
        self,
        texts: List[str],
        *,
        instruction: Optional[str] = None,
        is_query: bool = False,
    ) -> np.ndarray:
        """Return an (N, dim) float32 array. L2-normalized if self.normalize."""

    def encode_one(self, text: str, *, instruction=None, is_query=False) -> np.ndarray:
        return self.encode([text], instruction=instruction, is_query=is_query)[0]

Every encoder receives an optional instruction and an is_query flag so encoders that distinguish query vs. document roles (GritHopper, NV-Embed) can pick the right prompt. SBERT-style encoders ignore is_query.

load_encoder(spec)

python
from latentgraphrag.encoders import load_encoder

# Strings dispatch through this factory.
load_encoder("GritHopper-7B")           # -> GritHopperEncoder
load_encoder("text-embedding-3-large")         # -> OpenAIEncoder
load_encoder("nvidia/NV-Embed-v2")             # -> NVEmbedV2Encoder
load_encoder("hash")                           # -> HashEncoder (deterministic, for tests)
load_encoder("some/unknown-model")             # -> ValueError (implement BaseEncoder for custom)

Dispatch is purely string-based. If you pass an already-constructed BaseEncoder it's returned unchanged.

Bundled encoders

GritHopperEncoder

default

The default encoder. Wraps `gritlm.GritLM` with multi-hop query / document instructions. Outputs L2-normalized float32.

from latentgraphrag.encoders.grithopper import GritHopperEncoder
pip install latentgraphrag[gritlm]

Default model: "GritHopper-7B"

OpenAIEncoder

API

Calls the OpenAI embeddings API (or any compatible endpoint via base_url). Defaults to text-embedding-3-large.

from latentgraphrag.encoders.openai import OpenAIEncoder
pip install latentgraphrag[openai]

Default model: "text-embedding-3-large"

NVEmbedV2Encoder

baseline

NV-Embed-v2 as the encoder. Uses HuggingFace transformers; supports bfloat16 / float16 inference.

from latentgraphrag.encoders.nvembed import NVEmbedV2Encoder
pip install latentgraphrag[nvembed]

Default model: "nvidia/NV-Embed-v2"

Writing a custom multi-hop encoder

LatentGraphRAG retrieval depends on multi-hop dense retrieval: at every hop the encoder receives the question concatenated with previously retrieved evidence. A custom encoder needs to handle that growing context well — that usually means a model trained for it, with explicit query / document role conditioning. Plain similarity encoders without role awareness tend to underperform here.

python
import numpy as np
from latentgraphrag.encoders.base import BaseEncoder

class MyMultiHopEncoder(BaseEncoder):
    dim = 768
    normalize = True

    def __init__(self, my_model):
        self._model = my_model

    def encode(self, texts, *, instruction=None, is_query=False):
        # Apply role-aware conditioning here — e.g. different instructions for
        # is_query=True vs is_query=False, or a context-aware adapter.
        vecs = self._model.encode(texts, is_query=is_query).astype(np.float32)
        return self._l2_normalize(vecs) if self.normalize else vecs

# Plug into the pipeline:
import latentgraphrag as lgr
rag = lgr.LatentGraphRAG(encoder=MyMultiHopEncoder(my_model), openie_llm="gpt-4o-mini")
