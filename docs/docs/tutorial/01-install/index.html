Tutorial 1: Install

Welcome. This tutorial walks you through a full LatentGraphRAG loop end to end — building a small graph, encoding documents and memories, running retrieval in every corpus mode, and measuring Recall@5 against gold documents. It takes ~5 minutes if you already have a Python 3.10+ environment.

What you'll build

By the end you'll have:

  • A persisted graph index over 5 mini-MuSiQue documents
  • Working chunk and memory FAISS indices
  • A side-by-side comparison of Document-Only, Memory-Only, Joint-Index, and Dual-Tree
  • A Recall@5 number you can plot

Install

That gives you the recommended stack:

  • GritHopper-7B as encoder
  • FAISS-CPU for ANN search
  • OpenAI client for OpenIE + verbalization

You'll also need an OpenAI-compatible API key — anything that speaks the Chat Completions API works (OpenAI, Azure OpenAI, or a local vLLM server):

Want to run OpenIE locally? Swap openai for vllm: pip install "latentgraphrag[faiss-cpu,gritlm,vllm]". vLLM with prefix caching batches the few-shot OpenIE prompts efficiently across a whole corpus.

Verify the install

If imports complete cleanly you're ready for step 2: building a graph.
