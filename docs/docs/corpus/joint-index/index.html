Joint-Index

Chunks and memories live in one combined index. The tree mixes documents and memories at any hop — whichever's a better match for the current context. No fusion step needed.

Compared to dual-tree

Joint-index is the "cheaper" cousin of dual-tree: one index, one search, no fusion. It works when documents and memories have comparable scores under the same encoder. Joint-Index Tree Search reaches 76.14 MuSiQue R@5 — competitive but not the peak, which dual-tree variants achieve.
