# Installation

LatentGraphRAG needs **Python 3.10 or newer**. It depends on Recursive Dense Retrieval (RDR; Anonymous,
2026), which supplies the encoder, the recursive search and the readout, so RDR is installed first.

<CodePanel code={INSTALL} title="shell" lang="bash" />

The steps in detail:

## 1. Install RDR

Download RDR from its anonymous repository,
[anonymous.4open.science/r/Recursive-Dense-Retrieval](https://anonymous.4open.science/r/Recursive-Dense-Retrieval),
and install it in editable mode. Its distribution name is `recursive-dense-retrieval`; it is imported as `rdr`.

```bash
pip install -e ./Recursive-Dense-Retrieval
python -c "import rdr"
```

## 2. Install latentgraphrag

Download this package from its anonymous repository,
[anonymous.4open.science/r/Anonymous-LatenGraphRag-57C9](https://anonymous.4open.science/r/Anonymous-LatenGraphRag-57C9),
and install it from the repository root:

```bash
pip install -e .
```

The base install covers knowledge inventories, both retrieval trees, projection and fusion, and the
retrieval metrics. Its dependencies are `recursive-dense-retrieval`, `numpy`, `torch` and `tqdm`.

## Optional extras

| Extra | Installs | Needed for |
| --- | --- | --- |
| `agent` | `openai`, `transformers` | `OpenAIChatModel` (agent, reader, grader) and the default query encoder of `DenseSearchTool` |
| `construction` | `hipporag>=2.0.0a4` | extracting triples with HippoRAG's OpenIE (`triples.extract_with_hipporag`) |
| `dev` | `pytest`, `ruff` | running the tests |

```bash
pip install -e ".[agent]"            # the ReAct agent and the evaluation models
pip install -e ".[construction]"     # optional: triple extraction with HippoRAG
pip install -e ".[dev]"              # the test suite
```

Propositions are extracted by calling PropRAG from a local checkout
(`propositions.extract_with_proprag`). PropRAG is not bundled and not installed by any extra, since its
repository ships without a license file. Loading existing triple and proposition files needs neither.

## Models

- **Retriever.** `LatentGraphRAG` takes an RDR checkpoint (a path or a model id), or any encoder object that
  RDR's `RecursiveRetriever` accepts. Device, batch size and dtype options are passed through to RDR.
- **Chat model.** The agent, the reader and the grader talk to any OpenAI-compatible endpoint, for example a
  local vLLM server. The paper uses one model, Qwen3.5-122B-A10B, for all three roles.
- **Agent search tool.** The default query encoder is Qwen3-Embedding-8B, loaded on first use through
  `transformers`.

## Check the installation

```bash
pytest tests
```

The unit tests run without model weights: they use hashed fake encoders and a scripted chat model. The parity
test against the paper's evaluator is skipped unless it is pointed at that evaluator
(see [Reproducing the paper](/docs/reproduce)).
