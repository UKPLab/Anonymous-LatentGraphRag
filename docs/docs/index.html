LatentGraphRAG · latentgraphrag

LatentGraphRAG

Constructed knowledge, composed at test time. The latentgraphrag package searches the source documents and the triples and propositions constructed from them with two recursive trees on Recursive Dense Retrieval, returns one ranking of source documents, and hands its top 10 to a ReAct agent as initial evidence.

from latentgraphrag import (
    PAPER, LatentGraphRAG, MemoryInventory, propositions, triples,
    BrowseCompGrader, DenseSearchTool, OpenAIChatModel, ReActAgent, Seed)

# 1. constructed knowledge: one memory index, triples + propositions
openie = triples.load_openie("openie.jsonl.gz")       # HippoRAG format
tri = triples.from_openie(openie, source_of=chunk_to_doc)
records = propositions.load_records("proprag_openie.json")  # PropRAG
pro = propositions.from_records(records, source_of=chunk_to_doc)
inventory = MemoryInventory.union(tri, pro)  # provenance merged

# 2. two recursive trees on RDR, fused at the source
lgr = LatentGraphRAG("path/to/rdr-checkpoint", config=PAPER)
index = lgr.build(documents, inventory)      # documents: {doc id: text}
result = lgr.search([question], index, k=10)[0]
result.ranking                               # [(doc id, score), ...]

# 3. a ReAct agent seeded with the ranking, graded as in the paper
llm = OpenAIChatModel(model="Qwen/Qwen3.5-122B-A10B",
                      base_url="http://localhost:8000/v1")
agent = ReActAgent(llm, DenseSearchTool(embeddings, texts, ids))
seed = Seed.from_ranking(result.ids, documents)   # top 10 documents
trajectory = agent.run(question, seed)
verdict = BrowseCompGrader(llm).grade(question, trajectory.output,
                                      gold_answer)

How it works

LatentGraphRAG is built on Recursive Dense Retrieval (RDR; Anonymous, 2026). It runs RDR's recursive search twice. The document tree D searches the source documents; the memory tree M searches the constructed knowledge, triples rendered as sentences and propositions. Every memory keeps a link π to the documents it was extracted from, so the memory readout is projected onto documents: a document receives the maximum score of the memories it supplied. The two views are then fused with CombMNZ, with weight 1 for the document view and 0.5 for the memory view, into a single document ranking.

The ranking can be read directly by a fixed reader (retrieve-then-read) or handed to a ReAct agent as its initial evidence (retrieval-first seeding). The package includes both, together with the grader and the metrics used in the paper.

What comes from RDR, what this package adds

Both trees use RDR unchanged. LatentGraphRAG depends on the RDR package and does not re-implement it.

From RDR

  • Encoder: the RDR checkpoint encodes documents, memories and every query state
  • Recursive search: each query state encodes the question together with the units observed so far
  • Global readout: one ranking over all states of a tree

Search strategies, readouts and the encoder are documented on the RDR project page.

Added by latentgraphrag

  • Knowledge construction: triples and propositions as memories, each with the documents it came from
  • Memory tree: RDR's tree with children selected by maximal marginal relevance
  • Projection to sources: memory scores become document scores
  • View fusion: document view and projected memory view become one document ranking
  • Joint index: documents and memories in one index, for the ablation
  • Seeded ReAct agent: the ranking as initial evidence of an agent with a search tool
  • Evaluation: reader, BrowseComp grader, list recall and recall@k
