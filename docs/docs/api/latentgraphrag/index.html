LatentGraphRAG

The main pipeline class. SentenceTransformers-style: one constructor, a couple of stateful methods, and full save/load round-trip support.

save(...) / load(...)

python
def save(self, save_dir: Optional[str] = None) -> None: ...

@classmethod
def load(
    cls,
    save_dir: str,
    *,
    config: Optional[LatentGraphRAGConfig] = None,
) -> "LatentGraphRAG"

save() persists the graph, memories table, and manifest. Embedding parquets are written incrementally during build_graph and need not be saved again. load() re-opens an index in a fresh process and restores everything, including the manifest's encoder/openie ids.

Configuration

python
from latentgraphrag import LatentGraphRAGConfig

@dataclass
class LatentGraphRAGConfig:
    encoder: str = "GritHopper-7B"
    openie_llm: Optional[str] = "gpt-4o-mini"
    verbalizer_llm: Optional[str] = "gpt-4o-mini"
    chunk_size: int = 512
    chunk_overlap: int = 50
    save_dir: str = "./lgrag_index"
    faiss_index_type: Literal["flat", "hnsw", "auto"] = "auto"
    faiss_device: str = "auto"
    normalize_embeddings: bool = True
    batch_size: int = 32

A small dataclass, intentionally smaller than the legacy 30-field BaseConfig. Search-time parameters live on the retrieve() call, not on the model.
