API

Signatures of the public names, grouped by module. Names marked top level are also importable from latentgraphrag directly. The guides explain how the pieces fit together.

latentgraphrag.construction

Guide. Top level: triples, propositions, chunk_id.

source_of is a mapping or a callable from a record's idx to a document id; records it does not know are skipped.

latentgraphrag.inventory

Top level: MemoryInventory.

latentgraphrag.config

Top level: LGRConfig, PAPER.

Field descriptions are on the Retrieval page.

latentgraphrag.retrieval

Guide; saving and loading: Index, save, reuse. Top level: LatentGraphRAG, LGRIndex, LGRResult, MMRTreeSearch, project, fuse, rank, VIEWS.

latentgraphrag.agent

Guide. Top level: ReActAgent, Seed, Trajectory, DenseSearchTool, RankFileFusedSearchTool, OpenAIChatModel.

latentgraphrag.evaluation

Guide. Top level: Reader, BrowseCompGrader, loose_final, retrieval_metrics.
