Combine the document and memory rankings into one. Toggle plain additive (s_D + s_M, with a γ ablation) vs. the paper's parameter-free Z-Agreement to see how per-query calibration changes the ranking.

Each block prints the top-3 documents and their cumulative scores. With a corpus this small, all configs converge on the same gold document — but the path scores expose how "sure" each one was. On real benchmarks the gaps between configurations show up clearly in Recall@5.
