LatentGraphRAG

Composing Constructed Knowledge at Test Time with Recursive Dense Retrieval

Anonymous ACL Submission
Anonymous CodeDocsTracesRDR (backbone)

Initial evidence changes answer quality and agent search

Document-only recursive retrieval with RDR outperforms all evaluated graph pipelines on the three benchmarks; adding triples and propositions further improves retrieval.

Recursive seeds improve agent accuracy on MuSiQue and the web pool, while reducing agent search calls by 46–54% compared with Plain ReAct (unseeded agent) across benchmarks.

⚠️Motivation

Graph Pipelines Depend on What Extraction Kept

Graph-based retrieval constructs facts and their connections before a question arrives, then retrieves through that structure. Extraction can miss relations, removing graph routes even when the source text retains the evidence.

Problem 1

⚠️Missing Edge

The awarded relation between Einstein and Nobel was never encoded in the graph. A query about his prize fails to traverse this gap.

Route lost: a relation that extraction did not keep cannot be traversed, even though the source passage still states it.

Problem 2

⚠️Missing Node

The entity Ulm was never extracted into the graph. Any query about Einstein's birthplace hits a dead end.

Subgraph lost: if an entity was never extracted, every relation attached to it disappears from the graph, though not from the documents.

The other paradigm: recursive dense retrieval conditions each lookup on observed text, discovering evidence paths as search unfolds. LatentGraphRAG keeps the constructed facts, but as evidence for recursive search, linked to the passages they came from.

Constructed Knowledge as Retrievable Memories

Graph pipelines turn LLM-extracted relations into a topology to traverse. LatentGraphRAG keeps the same units as text: triples as the literal string “head relation tail.”, propositions as they are, in one memory index whose entries link back to their source passage through π(m), encoded into a dense index.

Two Trees, One Ranking: Source-Level Fusion

A document tree accumulates passages; a memory tree accumulates triples and propositions. Source links carry each memory's score to its passage, and CombMNZ fuses both views into one ranking.

RQ3

Less Brittle When Constructed Knowledge Is Missing

When answer-bearing or random triples and propositions are removed, LatentGraphRAG loses less recall than the graph pipelines built on them.

With propositions removed, LatentGraphRAG's document–proposition fusion loses 6.5 R@5 points, a third of PropRAG's 19.5.
With triples removed, document–triple fusion loses less than HippoRAG 2 (5.4 vs. 6.7 points) and stays above HippoRAG 2 with intact triples (75.7 vs. 71.4); adding propositions cuts the loss to 1.7.

On MuSiQue, every triple or proposition of the gold paragraph that mentions the hop answer is deleted (2,838 release triples, 2,568 PropRAG propositions), the same units for every system; the documents stay unchanged. Hop-level R@5 on the affected hops, before and after.

RQ4

Retrieval-First Seeds for Readers and Agents

Recursive seeds improve agent accuracy on MuSiQue and the web pool, while reducing agent search calls by 46–54% compared with Plain ReAct (unseeded agent) across benchmarks.

From the ranking to an answer, step by step

Retrieval-first seeding on three released questions, one per problem type: the two trees build the ranking, its top 10 documents become the agent's initial evidence, and the agent searches only for what the seed does not hold.

  3. →Virginia is bordered by the Atlantic Ocean
  4. →Atlantic hurricanes form usually in the summer or fall

Mean accuracy is 15.1 points higher with the LatentGraphRAG seed than with Plain ReAct on MuSiQue and 19.8 points higher on BrowseComp+ (pool); against HippoRAG 2 seeds, the gains are 4.5 and 9.5 points.
Relative to the unseeded agent, the LatentGraphRAG seed reduces mean agent input tokens by 16% on MuSiQue, 21% on FanOutQA, and 28% on BrowseComp+ (pool).
On FanOutQA, the clearest benefit of seeds is fewer searches at similar observed answer quality.
