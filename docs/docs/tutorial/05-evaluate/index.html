Tutorial 5: Evaluate

The headline retrieval metric is Recall@K — fraction of gold supporting documents that appear in the top-K retrieved. The package ships recall_at_k, qa_exact_match, and qa_f1 for the standard evaluation loop.

A tiny labeled set

For the mini corpus, we'll annotate two questions with their gold doc ids. In practice you'd use the dataset's provided gold annotations.

The exact doc_ids come from your build_graph run — they're MD5 hashes of the source document text, prefixed with "doc-". You can inspect them via rag.store.nodes_of_kind("chunk") and walking back to doc_id attributes.
