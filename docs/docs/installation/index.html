Installation

LatentGraphRAG requires Python 3.10+. Install the base package from PyPI:

The base install ships the pipeline, all six search strategies, both fusion methods, and the deterministic HashEncoder used in tests. To run with the default encoder and ANN-accelerated search, install one or more extras.

Recommended setup

That gives you:

  • GritHopper-7B as the encoder.
  • FAISS-CPU for ANN search up to ~10M vectors.
  • OpenAI client for OpenIE (NER + triple extraction) and triplet verbalization, defaulting to gpt-4o-mini.

If you'd rather run OpenIE locally on your own GPUs, swap openai for vllm:

vLLM runs Llama / Qwen-style models with prefix caching across the few-shot OpenIE prompts, so indexing a large corpus stays fast.
