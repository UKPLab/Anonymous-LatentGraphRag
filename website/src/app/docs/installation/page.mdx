# Installation

LatentGraphRAG requires **Python 3.10+**. Install the base package from PyPI:

```bash
pip install latentgraphrag
```

The base install ships the pipeline, all six search strategies, both fusion methods, and
the deterministic `HashEncoder` used in tests. To run with the default encoder and
ANN-accelerated search, install one or more extras.

## Recommended setup

```bash
pip install "latentgraphrag[faiss-cpu,gritlm,openai]"
```

That gives you:

- **GritHopper-7B** as the encoder.
- **FAISS-CPU** for ANN search up to ~10M vectors.
- **OpenAI** client for OpenIE (NER + triple extraction) and triplet verbalization, defaulting to `gpt-4o-mini`.

If you'd rather run OpenIE locally on your own GPUs, swap `openai` for `vllm`:

```bash
pip install "latentgraphrag[faiss-cpu,gritlm,vllm]"
```

vLLM runs Llama / Qwen-style models with prefix caching across the few-shot OpenIE
prompts, so indexing a large corpus stays fast.

## Available extras

| Extra | What you get | When to use |
|-------|--------------|-------------|
| `faiss-cpu` | `faiss-cpu>=1.7.4` for accelerated ANN search | Always recommended in production |
| `faiss-gpu` | `faiss-gpu>=1.7.4` for GPU-resident ANN | Large corpora (≥1M vectors) on a CUDA box |
| `gritlm` | `gritlm`, `torch`, `transformers` — runs GritHopper | The default encoder |
| `openai` | The official `openai` SDK | OpenIE + verbalization via API |
| `vllm` | `vllm`, `torch`, `transformers` | Self-hosted Llama / Qwen for OpenIE |
| `nvembed` | `torch`, `transformers` for NV-Embed-v2 | Using NV-Embed-v2 as the encoder |
| `all` | Everything except `faiss-gpu` | Kitchen sink |
| `dev` | `pytest`, `ruff`, `mypy` | Contributing to the package |

You can stack extras:

```bash
pip install "latentgraphrag[faiss-cpu,gritlm,vllm]"
```

## Verifying the install

```python
import latentgraphrag as lgr

print(lgr.__version__)
print(lgr.LatentGraphRAG)  # should be a class, not None
```

Once you can import the package, head to the **[Quickstart](/docs/quickstart)** for a five-minute end-to-end walkthrough.
